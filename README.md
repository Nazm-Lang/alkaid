# alkaid

**RFCs and governance for the Nazm language.**

*Alkaid*, "the leader" — the star at the end of the Great Bear's handle.

## Status

**Planned — nothing here yet.** Proposals for changes to the language, the standard library and the project's process. Today they are OpenSpec changes inside the compiler repository.

This repository is part of [Nazm](https://github.com/Nazm-Lang/nazm), a natively compiled
programming language with specified semantics. Nazm is at 0.9.0, a public preview of the 1.0
draft for macOS on Apple Silicon, with no compatibility promise until 1.0 — see
[nazm.dev](https://nazm.dev).
